# Destination Mood Board

A simple, responsive-style destination mood board built as a FreeCodeCamp lab exercise using **React, HTML, and CSS**. The page presents three travel-inspired images—Santorini, a shore, and a pathway—inside a colorful grid layout.

## Features

- Displays a **Destination Mood Board** heading.
- Shows three destination-themed cards with images and labels.
- Uses individual background colors for each mood board item.
- Arranges the cards in a three-column CSS Grid layout.
- Uses reusable React components to keep the interface organized.

## Technologies Used

- **HTML5** – page structure
- **CSS3** – styling, layout, colors, and image presentation
- **JavaScript (ES6+)** – component logic
- **React 18** – reusable UI components
- **Babel Standalone** – transforms JSX in the browser
